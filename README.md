## 🚀 Fitur Utama
- **Realtime State (<1s)**: Sinkronisasi status ESP32, toggle aktifasi akun mahasiswa, dan riwayat presensi langsung via Firebase Realtime Database.
- **Deteksi Cepat (15s)**: ESP32 memantau notifikasi pembukaan presensi dosen tanpa membebani server/IP bans.
- **Eksekusi Paralel Cloud**: Saat sesi dibuka, GitHub Actions langsung memproses presensi semua akun mahasiswa yang aktif.
- **Notifikasi WhatsApp**: Notifikasi personal via Fonnte ke nomor WhatsApp masing-masing mahasiswa.

ATTENTION!!
Using automated attendance may violate campus policy, use at your own risk.
